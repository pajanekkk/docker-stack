# docker-stack

<h2>O co se jedná?</h2>

- Pro použití a správné fungování stacku a databáze je nutné používat tyto soubory.
- originály jsou k dispozi zde: https://github.com/hrbolek/_uois

<h3>Použití</h3>

- prvotní inicializace - docker compose -f docker-compose.hk2026.yml pull
- zapnutí - docker compose -f docker-compose.hk2026.yml up -d
- vypnutí - docker compose -f docker-compose.hk2026.yml down
